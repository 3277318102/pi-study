# 分支工作流

## 分支命名

学习分支使用下面的格式：

```text
pi-MMDD-YYYY
```

- `MMDD`：月和日；
- `YYYY`：年份；
- 示例：`pi-1105-2026` 表示 2026 年 11 月 5 日的学习分支。

## 日常流程

1. 检查 `pi/` 当前分支、工作区状态和远程仓库配置。
2. 原始仓库有更新时，将上游变化同步到用户 Fork 的 `main`。
3. 从最新 `main` 创建当日学习分支。
4. 在学习分支中运行、阅读和分析原项目。
5. 将复刻代码写入 `c-pi/`，将学习结论写入 `c-pi/docs/`。
6. 比较不同学习分支，确认上游变化和自己的学习进展。

## Git 操作边界

Git 远程名称可能与预期不同，因此操作前必须查看实际配置。不要在未确认状态时直接同步、合并或推送。

Agent 不应自动执行以下操作：

- 切换或删除分支；
- 合并、变基或改写历史；
- 提交或推送代码；
- 清理未提交文件；
- 修改远程仓库地址。

这些操作只有在用户明确要求，并且当前状态已经核对后才能执行。
