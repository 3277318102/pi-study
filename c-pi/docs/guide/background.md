# 项目背景

## 学习目标

这个项目用于细致学习并逐步复刻 [Pi](https://github.com/earendil-works/pi)。目标不是快速复制全部源码，而是先理解它的功能、运行方式和实现思路，再通过小步实现建立完整认识。

AI 可以生成代码，但学习过程必须包含代码阅读。每一步都需要弄清楚：

- 这个功能解决什么问题；
- 用户可以观察到什么行为；
- 原项目怎样实现；
- 为什么采用这种实现；
- 怎样运行和验证结果。

## 仓库与目录

| 位置 | 用途 |

| `c-pi/` | 逐步复刻 Pi 的学习项目 |
| `c-pi/docs/` | 当前 VitePress 学习文档站点 |

## 当前约定

- `pi/` 默认作为源码参考，除非学习步骤明确需要，否则不直接修改。
- 新的学习实现放在 `c-pi/`，不要一次性复制完整原项目。
- 学习结论、命令和验证结果持续写入本目录。
- 根目录 `AGENTS.md` 是 Agent 跨对话继续工作的背景说明。
