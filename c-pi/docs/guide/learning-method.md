# 学习方法

## 开始一个功能前

1. 在 `pi/` 中找到功能入口和相关文件。
2. 运行原项目，观察功能的实际表现。
3. 阅读入口、调用链、数据结构和相关测试。
4. 用自己的语言说明功能目标与核心机制。
5. 将实现拆成可以独立验证的最小步骤。

## 逐步复刻

每次只实现一个小而完整的能力：

1. 定义本步目标和预期行为；
2. 写出最小实现；
3. 运行或测试；
4. 对照原项目行为；
5. 修正差异；
6. 记录实现、命令和验证结果；
7. 再进入下一步。

不要为了追求进度提前加入当前步骤不需要的抽象、兼容层或附加功能。

## 每步学习记录模板

后续可以按下面的结构新增文档：

```markdown
# 功能名称

## 学习目标

## 原项目行为

## 相关源码

## 最小实现

## 运行与验证

## 与原项目的差异

## 本步总结

## 下一步
```
